## Science & Math

- [arXiv](https://arxiv.org) - Open-access preprint server for physics, mathematics, computer science, and related fields.
- [Return to Mathematical Circles](https://www.amazon.com/Return-Mathematical-Circles-Collection-mathematics/dp/0871501058) - A fifth collection of mathematical stories and anecdotes for curious readers.
- [Low Tech Magazine](https://solar.lowtechmagazine.com) - Journal about low-tech, sustainable solutions, published on a solar-powered website.
- [Creative Commons](https://creativecommons.org) - Free, standard licenses for sharing and reusing creative and academic work.
- [Project Gutenberg](https://gutenberg.org) - Free library of more than 70,000 public-domain ebooks, from classics to science.
- [Wolfram Alpha](https://www.wolframalpha.com) - Computational knowledge engine that answers questions with curated data.
- [OEIS](https://oeis.org) - The On-Line Encyclopedia of Integer Sequences, the reference database for integer sequences.
- [Khan Academy](https://www.khanacademy.org) - Free online courses and practice exercises in math, science, and computing.
- [MIT OpenCourseWare](https://ocw.mit.edu) - Free course materials from MIT spanning math, physics, and engineering.
- [iNaturalist](https://www.inaturalist.org) - Citizen science platform for recording and identifying plant and animal observations.
- [Wikipedia](https://www.wikipedia.org) - Free, collaboratively edited encyclopedia and a primary starting point for research.

## Web Archival & Preservation

- [Internet Archive](https://archive.org) - Nonprofit digital library preserving web pages, books, audio, and video.
- [Wayback Machine](https://web.archive.org) - The Internet Archive's historical snapshot of the web, searchable by URL.
- [Wayback Machine Chrome Extension](https://chromewebstore.google.com/detail/wayback-machine/fpnmgdkabkmnadcjpehmlllkndpkmiak) - Save pages and check archived versions directly from the browser.
- [Wayback Machine Firefox Extension](https://addons.mozilla.org/en-US/firefox/addon/wayback-machine_new/) - Firefox version of the official Wayback Machine add-on.
- [Wayback Machine WebExtension (source)](https://github.com/internetarchive/wayback-machine-webextension) - Open-source code for the official browser extensions.
- [Web Archives](https://github.com/dessant/web-archives) - Browser extension for viewing archived and cached versions of web pages across multiple services.
- [Archive.today](https://archive.today) - On-demand web archive service that creates permanent snapshots of any page.
- [Common Crawl](https://commoncrawl.org) - Nonprofit that crawls the web and makes petabytes of open crawl data available for research.
- [Archive-It](https://archive-it.org) - Internet Archive's web archiving service for libraries and institutions building curated collections.
- [Perma.cc](https://perma.cc) - Service that creates permanent citations of web pages for legal and academic work.
- [Memento](https://mementoweb.org) - Protocol and aggregator for finding archived copies of web pages across many archives.
- [Software Heritage](https://softwareheritage.org) - Nonprofit archive that collects all publicly available source code for preservation.
- [ArchiveBox](https://archivebox.io) - Self-hosted "Wayback Machine" that saves pages you choose into a browsable offline archive.
- [Heritrix](https://github.com/internetarchive/heritrix3) - Internet Archive's open-source web crawler built for large-scale archiving.
- [Brozzler](https://github.com/internetarchive/brozzler) - Distributed crawler from the Internet Archive that drives headless browsers for hard-to-crawl pages.
- [Conifer](https://conifer.rhizome.org) - Web archiving tool from Rhizome that records pages interactively as you browse.
- [Webrecorder](https://github.com/webrecorder/webrecorder) - Earlier Rhizome tool for interactive web recording; succeeded by Conifer.

## No-Degree Tech Careers

- [roadmap.sh](https://roadmap.sh) - Community roadmaps showing what to learn for different developer career paths.
- [freeCodeCamp](https://www.freecodecamp.org) - Free, nonprofit curriculum and certifications for web development.
- [The Odin Project](https://www.theodinproject.com) - Free full-stack web development curriculum built on open-source materials.
- [Google Career Certificates](https://grow.google/certificates/) - Job-ready certificate programs in IT, data analytics, and UX from Google.
- [GitHub Skills](https://skills.github.com) - Hands-on, interactive courses for learning Git and GitHub.
- [CompTIA](https://www.comptia.org) - Vendor-neutral IT certification body covering A+, Network+, and Security+.
- [MDN Web Docs](https://developer.mozilla.org) - Mozilla's documentation for web technologies and the standards behind them.

## Single-Board Computers & Electronics

- [Raspberry Pi](https://www.raspberrypi.com) - Affordable single-board computers for learning, hobby, and embedded projects.
- [Raspberry Pi Pico](https://www.raspberrypi.com/products/raspberry-pi-pico/) - Microcontroller boards from the Raspberry Pi foundation, programmable in C and MicroPython.
- [Pine64](https://www.pine64.org) - Maker of open, affordable single-board computers and Linux phones.
- [BeagleBoard](https://beagleboard.org) - Open-hardware single-board computers focused on embedded Linux development.
- [Arduino](https://www.arduino.cc) - Open-source electronics platform and IDE for building interactive hardware projects.
- [ESP32](https://www.espressif.com/en/products/socs/esp32) - Low-cost, low-power microcontroller with Wi-Fi and Bluetooth, a staple of IoT projects.
- [Adafruit](https://www.adafruit.com) - Electronics retailer and learning hub with tutorials and open-source hardware.
- [SparkFun](https://www.sparkfun.com) - Electronics retailer offering parts, breakout boards, and tutorials.

## FPGA & HDL Design

- [Icarus Verilog](https://github.com/steveicarus/iverilog) - Open-source Verilog compiler and simulator, a common first step into HDL.
- [Verilator](https://www.verilator.org) - High-performance Verilog and SystemVerilog simulator that compiles designs to C++ for simulation.
- [Yosys](https://yosyshq.net/yosys/) - Open-source synthesis suite for Verilog that maps designs to FPGAs and ASIC flows.
- [Project IceStorm](https://github.com/cliffordwolf/icestorm) - Reverse-engineered Lattice iCE40 FPGA toolchain that opened up low-cost FPGA hacking.
- [nextpnr](https://github.com/YosysHQ/nextpnr) - Portable FPGA place-and-route tool that pairs with Yosys.
- [OpenLane](https://github.com/The-OpenROAD-Project/OpenLane) - Open-source ASIC design flow built on Yosys, OpenROAD, and Magic.

## Amateur Radio & Software-Defined Radio

- [ARRL](https://www.arrl.org) - The national association for amateur radio in the United States, with licensing information.
- [WSJT-X](https://physics.princeton.edu/pulsar/k1jt/wsjtx.html) - Digital mode software for weak-signal ham radio communication such as FT8 and WSPR.
- [GNU Radio](https://www.gnuradio.org) - Open-source toolkit for building software-defined radio applications with signal processing blocks.
- [SDR++](https://github.com/AlexandreRouma/SDRPlusPlus) - Cross-platform software-defined radio receiver program.
- [RTL-SDR Blog](https://www.rtl-sdr.com) - Community resource around cheap RTL-SDR dongles and software-defined radio projects.
- [KiwiSDR](https://kiwisdr.com) - Web-enabled SDR receivers that let you tune HF radio from your browser.
- [QRZ](https://www.qrz.com) - Amateur radio callsign database, logbook, and community hub.
- [EchoLink](https://echolink.org) - Software that links ham radio repeaters and stations over the internet.
- [HamStudy](https://hamstudy.org) - Free study tools and practice exams for amateur radio licensing.
- [Logbook of The World](https://lotw.arrl.org) - ARRL's online system for confirming ham radio contacts electronically.
